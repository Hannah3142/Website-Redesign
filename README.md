Hellow Reader!

In this project, I started to redesign a website for the New Zealand charity Te Wāhi Ora ([current website](https://www.tewahiora.co.nz/)), which offers retreats from women for women.
I used Cursor to code an interactive design and refine it. Once they were happy with it, the website would have been build in Wordpress, but before I am even done with the design the project has been put on pause and I won't be able to continue in the future, so this is unfinished : &#40;

To preview the current design, open a terminal in the handover folder and run python3 -m http.server 8766. Then open http://127.0.0.1:8766/preview/index.html in a browser, but it's not different to the demo link on [vercel](https://website-redesign-ten-chi.vercel.app/handover/preview/index.html).

The Home page, the stay pages and the overview page for what we offer are the furthest developed, but I couldn't do more before the project was paused. The content is often deliberatly lorem ipsum and the images won't be used, because Te Wāhi Ora said they want to supply the copy and I didn't have many images from them.

This was my first real project and I hope this Readme has all the content it needs.
