# Te Wāhi Ora website redesign

This repository is **design work**, paused November 2026. The live website is still WordPress at [tewahiora.co.nz](https://www.tewahiora.co.nz/). The next site will also be WordPress. Nothing here is the live site.

**If you are picking this up, start in [`handover/`](handover/).** That folder has the brief, Jordan’s direction, the brand style guide, what is still open, a booking-and-payment draft, and a clickable preview of the look we were refining.

The rest of the repo is earlier exploration (sitemap options A / B / C, older clickable prototypes). The preview we were actually improving is option C: `clickable-sitemaps/designed-merge/` in this repo, and a copy without the sitemap bar in `handover/preview/`.
